# Project Scan Summary

## Project overview
This repository is a static website for Royal Goa Ride, built with plain HTML, CSS, and JavaScript. The site is focused on car rental marketing, SEO, and WhatsApp/phone conversion flows.

## Project structure
- Root HTML pages for the main website and landing pages
- Shared CSS files: styles.css and styles-google-reviews.css
- Shared JavaScript: script.js
- Assets folder for images and branding files
- SEO and PWA files: robots.txt, sitemap.xml, sitemap-locations.xml, sitemap-vehicles.xml, sitemap-guides.xml, manifest.json, browserconfig.xml
- Blog folder with additional content pages

## Technologies used
- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap Icons via CDN
- JSON-LD structured data
- Open Graph and Twitter meta tags
- Google Analytics / Google Ads tags
- XML sitemaps and robots.txt

## Important notes
- The project is static and does not appear to use a framework or build system.
- SEO and conversion optimization are important goals.
- Shared navigation and footer behavior are handled through JavaScript.
- Many content pages are similar and may share repeated structure.

## Potential issues / duplicate patterns
- Repeated HTML boilerplate and SEO blocks across many pages
- Some canonical links appear inconsistent across policy/booking pages
- Legacy CSS file may be redundant or unused in some cases
- Shared layout behavior depends on script.js being included on each page
