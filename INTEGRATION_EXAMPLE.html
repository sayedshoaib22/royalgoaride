🔍 Royal Goa Ride - Google Reviews Integration

Step-by-Step Integration Guide

Follow these steps to add the Real Google Reviews section to your website.

1️⃣ Add CSS Link to Your HTML Head

Add this line in your <head> section:

<!-- Google Reviews Styles -->
<link rel="stylesheet" href="styles-google-reviews.css" />

2️⃣ Load Configuration & Scripts

Add these script tags before your closing </body> tag:

<!-- Google Reviews Configuration -->
<script src="js/google-reviews-config.js"></script>

<!-- Google Reviews Widget -->
<script src="js/google-reviews-widget.js" defer></script>

3️⃣ Add the Reviews Section HTML

Copy the entire content from google-reviews-section.html and paste it into your page where you want the reviews to appear.

Typically after your testimonials section or before the footer.

4️⃣ (Optional) Configure Google Places API

To fetch real, live reviews directly from Google:

// In js/google-reviews-widget.js, line ~15
this.googleMapsApiKey = 'YOUR_GOOGLE_PLACES_API_KEY';

Replace with your actual Google Places API key.

🎨 Customization Examples

Change Refresh Rate

In js/google-reviews-widget.js:

// Refresh every 30 minutes instead of 1 hour
this.refreshInterval = 1800000; // 30 minutes

Show More/Fewer Reviews

In js/google-reviews-widget.js, find line with .slice(0, 8):

// Show 12 reviews instead of 8
this.displayReviews(reviews.slice(0, 12));

Change Color Scheme

In styles-google-reviews.css:

/* Change gold color to your brand color */
:root {
  --gold: #YOUR_COLOR_HERE;
}

🐛 Troubleshooting

Issue: Reviews not showing

Solution:

  • Check browser console for errors (F12)
  • Verify js/google-reviews-widget.js path is correct
  • Check that styles-google-reviews.css is loaded

Issue: Styling looks wrong

Solution:

  • Clear browser cache (Ctrl+Shift+Delete)
  • Verify styles-google-reviews.css path is correct
  • Check that no other CSS conflicts with review styles

Issue: Reviews not updating

Solution:

  • Verify Google Places API key is set (if using live API)
  • Widget uses cached reviews as fallback
  • Refresh interval set to 1 hour by default
