🚀 5-Minute Setup Process

1
Open your index.html file

Find the <head> section

2
Add CSS link
<link rel="stylesheet" href="styles-google-reviews.css" />
3
Find your closing </body> tag

Add JavaScript before it

4
Add JavaScript loader
<script src="js/google-reviews-widget.js" defer></script>
5
Add HTML section

Copy content from MINIMAL_COPY_PASTE_EXAMPLE.html

Paste where you want reviews to appear
